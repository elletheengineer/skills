# Elle the Engineer skills

Free Claude skills from [Elle the Engineer](https://x.com/elletheengineer), by Elle the Engineer. Every blog post comes with a skill that helps you do the thing the post explains.

Repo: https://github.com/elletheengineer/skills

## Install
1. Download the skill's folder.
2. Copy it into `~/.claude/skills/` (for all your projects) or a project's `.claude/skills/` folder.
3. Start a new Claude Code session. The skill turns on when your request matches it, or call it by name.

Each skill's README has an example prompt and links to the post it comes from.

## Skills

| Skill | What it helps you do | Post |
|---|---|---|
| [explain-it-back-machine-learning](explain-it-back-machine-learning/) | Explain how machine learning works in your own words; it names what's missing and asks one question per gap until you've got it | How AI learns: by being wrong, a little less each time (X) |
